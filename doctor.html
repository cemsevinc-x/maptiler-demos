Every map load is billed as four requests instead of one

The page uses 512px raster tiles. Each one counts as four requests. That is about 1.6M of this month's 2.1M.

What we saw
GET /maps/streets-v2/14/8192/5461@2x.png 412 raster tiles on first view, all @2x (512px)
Fix
const map = new maptilersdk.Map({
  container: 'map',
  style: maptilersdk.MapStyle.STREETS,   // vector: one request per tile
  center: [-1.6, 54.97], zoom: 11
});

Your own layers disappear when the style changes

The page switches styles three times and nothing re-adds the spot markers afterwards. Users who switch to Satellite lose them.

What we saw
map.setStyle() ×3 · addLayer runs once at load · no style.load handler
Fix
const spots = new Map();
let styleReady = false;

function drawSpot(id, entry) {
  spots.set(id, entry);
  if (!styleReady) return;                 // style.load draws it
  if (!map.getSource(id)) map.addSource(id, { type: 'geojson', data: entry.geojson });
  if (!map.getLayer(id))  map.addLayer({ id, type: 'circle', source: id });
}
function switchStyle(style) { styleReady = false; map.setStyle(style); }
map.on('style.load', () => { styleReady = true; spots.forEach((e, id) => drawSpot(id, e)); });
Docs

Not documented yet. Keep custom layers across style changes. Example tested on SDK 4.1.0.

All tiles come through one server, so one IP carries the load

Tiles are proxied through tiles.northsea-surf.example. Rate limits apply per IP, and 38% of requests were rejected in the last hour.

What we saw
origin IP 203.0.113.7 · ~12k requests/hour · HTTP 429 on 38%
Fix

Let browsers request tiles directly, with an origin-restricted key. If the proxy has to stay, agree it with sales first.

Searching for a landmark returns nothing

Geocoding requests go out without a types parameter, and points of interest are not included by default. Place names work, landmarks don't.

What we saw
/geocoding/Grey's%20Monument.json → streets only
Fix
geocoding.forward(q, { types: ['poi', 'place', 'address'], country: ['gb'] })
Docs

Geocoding API. Missing one line: poi is excluded by default.
