# MapTiler demos

Small pages built while working through the SDK and its plugins. Each one is a
single HTML file with no build step.

    objects3d.html    glTF meshes placed on the map by coordinate

## Running locally

    cp config.example.js config.js     # then put your own key in
    python3 -m http.server 8050

The published version uses a key restricted to this site's origin.
